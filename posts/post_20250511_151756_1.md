"Revolutionizing Business Process Management with AI! 🤖

Imagine redesigning process models with ease, using natural language requests. Researchers explored the feasibility of using large language models (LLMs) to empower domain experts in creating and redesigning process models iteratively and effectively.

The conversational process model approach:

1️⃣ Identifies process change patterns from literature
2️⃣ Rephrases the change request to align with the pattern's meaning
3️⃣ Applies the change to the process model

This multi-step approach enables explainable and reproducible changes. The evaluation results show that LLMs can handle changes well, but users need support to describe changes clearly.

Impact and use cases:

* Streamlined process model redesign
* Enhanced collaboration between humans and LLMs
* Improved process model quality and consistency
