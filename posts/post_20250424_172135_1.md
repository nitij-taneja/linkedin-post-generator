Function Calling & MCP: A Shift in AI Workflows

• Function Calling: A mechanism that allows LLMs to recognize what tool they need based on user input and when to invoke it. It involves the LLM deciding the tool, implementing procedures to accept tool calls, and passing function calls to backend services for execution.

• MCP (Model Context Protocol): A new standard for structuring tool access and orchestration for agents, introducing a shift away from traditional function calling.
